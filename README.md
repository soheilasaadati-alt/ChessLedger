# ChessLedger — دفتر حساب کلاس شطرنج سویل

Kotlin + Jetpack Compose. ذخیره‌سازی محلی در فایل JSON (`ledger.json` در حافظه داخلی اپ).
داده‌های سال ۱۴۰۵ (جلسات ۵ تا ۴۶، پرداخت‌ها، تی‌شرت، مسابقه، کتاب‌ها) در `Data.kt` بخش `Seed` هست و فقط بار اول اجرا وارد می‌شود.

- Android Studio: پوشه را باز کن و Sync کن.
- GitHub Actions: هر push یک APK دیباگ می‌سازد (Artifacts).
